## 项目亮点速览

| 亮点 | 说明 |
|------|------|
| 全 Rust 编写 | 67 个 crates，编译为原生二进制，单会话仅 27.8MB 内存 |
| 7 层架构 | CLI（命令行界面，敲命令操作）入口 → 应用编排 → Agent 核心 → TUI（终端图形界面，有菜单和面板）界面 → 服务层 → 工具层 → 基础设施 |
| 三级记忆系统 | L1 会话记忆 / L2 项目记忆 / L3 全局记忆，跨会话持久化 |
| Swarm 多 Agent | 多个 Agent 像团队一样协作，分工处理复杂任务 |
| 8+ Provider | Anthropic/OpenAI/Gemini/Copilot/Bedrock/Cursor，一行配置切换 |
| 本地优先 | ONNX（通用 AI 模型格式，本地运行不需联网）向量嵌入在本地完成，数据不出本机 |

## 文档特点

- 面向产品经理、运营、非技术人员编写，技术概念用大白话解释
- 基于 CodeGraph（38,815 节点）+ UA 知识图谱（16 节点）双重验证
- 7 层 ASC-II 架构图，逐层深入详解
- 67 个 crates 全部覆盖，无遗漏
- 架构决策记录（ADR）解释关键设计选择及原因
