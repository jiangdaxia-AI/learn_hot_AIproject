# 06 — 数学动画 Agent（Math Animator）

> **源码位置**：`deeptutor/agents/math_animator/`（10 个文件）
> **阅读对象**：产品经理 / 运营

---

## 一句话概括

数学动画 Agent 是 DeepTutor 的"动画老师"。它能把抽象的数学概念（如函数图像、几何变换、微积分过程）变成可视化的动画，帮助学生直观理解。

## 生活化比喻

> 就像数学课上的几何画板——老师画一个圆，你能看到圆的形成过程；老师画一条抛物线，你能看到曲线随参数变化。数学动画 Agent 就是把这个过程自动化了。

## 核心文件

| 文件 | 职责 |
|------|------|
| `pipeline.py` | 动画生成管线：需求分析 → 代码生成 → 渲染 |
| `capability.py` | 能力入口：接收用户请求，判断能否处理 |
| `renderer.py` | 渲染器：把生成的代码渲染成动画 |
| `model.py` | 数据模型：动画参数定义 |

## 对产品/运营的一句话总结

> 数学动画 Agent 让抽象的数学概念变成可视化的动画，帮助学生从"看公式"变成"看动画"，理解更直观。
