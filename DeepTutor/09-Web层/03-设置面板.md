# 设置面板 — DeepTutor 的"控制中心"

> Understand-Anything 知识图谱: 26 节点, 25 边, 7 层
## 一句话说明

设置面板是 DeepTutor 的**管理控制台**，管理员和高级用户在这里配置系统的所有核心参数——从 LLM 模型切换到外观主题，从知识库管理到聊天行为调优，无需修改一行代码。

---

## 业务价值

- **零代码配置**：所有模型服务（LLM、Embedding、TTS、STT、搜索、图像生成、视频生成）都可以通过 UI 配置，不需要编辑配置文件。
- **多服务商支持**：同一类服务可以配置多个服务商（如同时配置 OpenAI、Anthropic、本地模型），运行时灵活切换。
- **实时诊断**：内置服务健康检查，一键检测所有配置的服务是否可用，失败的标红提示。
- **分层管理**：设置分为"全局默认"和"会话级覆盖"两个层级，管理员设置全局默认，用户在聊天中可临时覆盖。
- **引导式上手**：内置"设置导览"（Tour），帮助新管理员快速了解每个配置项的作用。

## 服务配置编辑器 (`ServiceConfigEditor.tsx`)

**路径**：`web/components/settings/ServiceConfigEditor.tsx`（第 1-1600+ 行）

**这是设置面板中最大、最核心的组件**，负责配置所有 AI 服务的提供商和模型。

### 支持的服务类型

**定义**：`SettingsContext.tsx` 第 22-29 行

| 服务 | 标识 | 业务含义 |
|------|------|---------|
| LLM | `llm` | 大语言模型（对话、推理、生成） |
| Embedding | `embedding` | 文本向量化（知识库检索） |
| Search | `search` | 网络搜索（深度研究用） |
| TTS | `tts` | 文本转语音（朗读功能） |
| STT | `stt` | 语音转文本（语音输入） |
| ImageGen | `imagegen` | 图像生成 |
| VideoGen | `videogen` | 视频生成 |

### 配置结构

每个服务类型下可以配置**多个 Profile**（服务商配置文件），每个 Profile 包含：

```
服务 (如 LLM)
├── 活跃 Profile：选中的那个
├── Profile 1：OpenAI
│   ├── 名称：OpenAI
│   ├── 提供商：openai
│   ├── Base URL：https://api.openai.com/v1
│   ├── API Key：[已加密]
│   ├── API Version：（可选）
│   ├── 额外请求头：（可选）
│   ├── 代理：（可选）
│   └── 模型列表：
│       ├── gpt-4o
│       │   ├── 上下文窗口：128k
│       │   └── 维度：—
│       ├── gpt-4o-mini
│       │   ├── 上下文窗口：128k
│       │   └── 维度：—
│       └── gpt-3.5-turbo
│           ├── 上下文窗口：16k
│           └── 维度：—
├── Profile 2：Anthropic
│   ├── 名称：Anthropic
│   ├── 提供商：anthropic
│   └── ...
└── Profile 3：本地模型 (Ollama)
    ├── 名称：Local
    ├── 提供商：openai（兼容 API）
    ├── Base URL：http://localhost:11434/v1
    └── ...
```

### 交互功能

- **添加/删除 Profile**：可以为同一个服务类型配置多个服务商。
- **切换活跃 Profile**：运行时选择使用哪个服务商。
- **编辑 Profile 详情**：修改 Base URL、API Key、模型列表等。
- **模型管理**：添加/删除模型，设置上下文窗口大小、维度（Embedding 专用）、TTS 语音等。
- **上下文窗口自动检测**：对于支持的模型，可以一键检测实际上下文窗口大小。
- **诊断测试**：对每个 Profile 运行连通性测试，确认配置正确。

**源码位置**：`ServiceConfigEditor.tsx` 第 1-1600+ 行

## 设置上下文 (`SettingsContext.tsx`)

**路径**：`web/components/settings/SettingsContext.tsx`（第 1-1350+ 行）

**作用**：整个设置系统的"数据大脑"，管理所有设置的状态、加载、保存和诊断。

### 核心职责

1. **配置加载**：从后端 API 加载完整的 `Catalog`（服务配置目录）和 `UiSettings`（UI 设置）。
2. **状态管理**：维护当前编辑中的配置（草稿）和已保存的配置。
3. **保存机制**：将修改后的配置写回后端。
4. **诊断管理**：运行服务诊断测试，缓存结果。
5. **服务就绪状态**：计算每个服务的健康状态（`serviceReadiness` 函数）。

### 服务就绪状态

**函数**：`serviceReadiness(catalog, serviceName, diagnosticsResults)`（`SettingsContext.tsx`）

返回四种状态：
- `not_configured`：未配置
- `untested`：已配置但未测试
- `passed`：已配置且测试通过
- `failed`：已配置但测试失败

## 设置的数据流

```
┌─────────────────────────────────────────────────────────┐
│                    SettingsContext                       │
│  ┌─────────────┐  ┌──────────────┐  ┌───────────────┐  │
│  │ Catalog     │  │ UiSettings   │  │ Diagnostics   │  │
│  │ (服务配置)  │  │ (UI 设置)    │  │ Results       │  │
│  └─────────────┘  └──────────────┘  └───────────────┘  │
└────────────┬──────────────┬──────────────┬─────────────┘
             │              │              │
    ┌────────▼─────┐ ┌──────▼──────┐ ┌─────▼──────────┐
    │ Service      │ │ Theme       │ │ SettingsStatus │
    │ ConfigEditor │ │ PreviewCard │ │ Panel          │
    └──────────────┘ └─────────────┘ └────────────────┘
```

1. `SettingsContext` 从后端 API 加载全部配置。
2. 各个编辑器组件从 Context 读取数据，展示可编辑的 UI。
3. 用户修改 → 更新 Context 中的草稿 → 点击保存 → 写回后端。
4. 诊断结果独立于配置，可以随时运行/刷新。

## 与 Chat 界面的联动

设置面板的配置直接影响 Chat 界面的行为：

- **模型选择器**：Chat 输入框中的模型下拉菜单，数据来源于 Settings 中配置的 LLM 服务。
- **TTS 朗读**：Chat 消息的朗读功能使用 Settings 中配置的 TTS 服务。
- **语音输入**：使用 Settings 中配置的 STT 服务。
- **知识库选择器**：Chat 中的知识库范围选择器，知识库列表来源于 Settings 中的知识库配置。
- **子 Agent 调用**：Chat 中的 Agent 选择器，Agent 列表来源于 Settings 中的子 Agent 配置。

## 安全设计

- **API Key 加密**：所有 API Key 在后端加密存储，前端只显示脱敏版本（如 `sk-...xxxx`）。
- **权限控制**：非管理员用户访问设置 API 时返回 403，前端优雅降级（隐藏编辑功能，只读展示）。
- **确认对话框**：删除 Profile、重置配置等危险操作都有二次确认。

## 比喻总结

如果把 DeepTutor 比作一辆**智能汽车**，那设置面板就是它的**引擎盖下的配置面板**：

- 🔧 **模型与服务** = 选择发动机类型（汽油/电动/混动）和品牌（OpenAI/Anthropic/本地）
- 🎨 **外观** = 调整内饰颜色、座椅材质、仪表盘风格
- 🌐 **网络** = 设置导航系统的基础地图服务
- 📚 **知识库** = 管理车载图书馆的藏书
- 💬 **聊天与 Agent** = 调整 AI 助手的"性格"和"能力边界"
- 🧠 **记忆** = 管理 AI 对你的了解和偏好

普通用户（学生）不需要打开引擎盖，但管理员（教师/系统管理员）可以通过这个面板精细调校整个系统，让它以最佳状态运行。
