## 常见问题

### Q: 这本书和官方文档有什么区别？

官方文档（deeptutor.info）是使用手册，告诉你怎么用。这本书是源码剖析，告诉你内部怎么工作、为什么这样设计。两者互补。

### Q: 我不懂代码，能看懂吗？

能。本书刻意避免了代码细节，用比喻、流程图、ASCII图来解释架构和设计。偶尔出现的代码路径只是为了帮你定位，不是让你读的。

### Q: 这本书会更新吗？

DeepTutor迭代非常快（平均2-3天一个版本），本书基于v1.5.2（2026年7月19日）版本撰写。重大架构变更时会更新对应章节。

## 附录：常用术语对照

| 术语 | 英文 | 大白话解释 |
|------|------|-----------|
| Agent | 智能体 | 能自主调用工具、做决策的 AI |
| RAG | 检索增强生成 | 先查资料再回答，避免胡说八道 |
| LLM | 大语言模型 | 就是 GPT、Claude 这类 AI 模型 |
| Embedding | 向量嵌入 | 把文字变成一串数字，方便 AI 比较相似度 |
| Chunk | 文本块 | 把长文档切成小块，方便检索 |
| Vector DB | 向量数据库 | 专门存储和搜索"数字串"的数据库 |
| WebSocket | 网络套接字 | 一种实时通信方式，前端和后端保持长连接 |
| Pipeline | 流水线 | 一系列处理步骤的串联 |
| Provider | 服务提供商 | 提供模型服务的公司，如 OpenAI、Anthropic |
| Consolidator | 整合器 | 把零散事件整理成结构化摘要的组件 |
| Mastery | 掌握度 | 学生对某个知识点的掌握程度（0~1） |
| Spaced Repetition | 间隔重复 | 在即将遗忘时复习，记忆效果最好的学习方法 |
| Token | 令牌 | LLM 处理文本的最小单位，约等于 0.75 个英文单词 |
| Stream | 流式输出 | 逐字返回结果，用户看到打字效果 |
| Tool Calling | 工具调用 | Agent 调用外部工具（如搜索、计算器） |
