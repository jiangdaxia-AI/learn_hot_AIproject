## 1. 一句话定位

**DeepTutor 是一个 AI 驱动的智能教学平台。** 它不是套壳 ChatGPT + 题库，而是一个以 Agent 自主决策为核心、以知识库检索为土壤、以长期记忆为大脑、以掌握度评估为导航的个性化辅导系统。

用一句大白话说：**DeepTutor 就像一个永不疲倦的私人家教，它记得你学过什么、哪里薄弱、什么时候该复习。**

---

## 2. 它能做什么？核心功能一览

### 智能对话（Chat）

不只是你问我答。DeepTutor 的聊天是 Agent 驱动的：
- AI 会自动判断我需要查知识库吗？需要搜索网页吗？需要运行代码吗？
- 然后它自己调用工具、获取结果、综合回答
- 整个过程用户可以看到 AI 在思考和工作中

### 知识库问答（RAG）

- 上传 PDF、Word、PPT、网页 -> 系统自动解析、向量化
- 提问时 AI 自动从知识库中检索相关内容
- 回答附带来源引用（sources），可以追溯到原始文档

### 智能出题

- 基于知识库/教材内容自动生成题目
- 支持选择题、填空题、简答题
- 支持试卷模拟（exam_mimic）

### 掌握度追踪（Mastery Path）

- 7 阶段学习路径：诊断 -> 讲解 -> 费曼检查 -> 练习 -> 错误诊断 -> 复习 -> 完成
- 4 种错误分类：知识结构性 / 理解偏差 / 应用错误 / 元认知
- 间隔重复算法：在遗忘临界点提醒复习

### 互动教材（Book Engine）

- 从知识库、聊天记录、笔记本中自动生成互动教材
- 包含文字、插图、测验、代码块、动画等多种内容块
- 支持概念图谱（Concept Graph）可视化

### 笔记本（Notebook）

- 自动保存有价值的问答、解题过程
- 支持分类、搜索、回顾
- 可作为教材生成的素材

### 工具生态

- 代码执行：AI 可以写 Python 代码并运行，生成图表、PDF
- 网页搜索：AI 可以搜索互联网获取最新信息
- 论文搜索：AI 可以搜索学术论文
- 图像分析：上传图片，AI 分析内容（如 GeoGebra 几何题）
- 定时任务（Cron）：AI 可以设置定时提醒
- 子代理：AI 可以启动子 AI 处理复杂任务

## 4. 解决的核心痛点

### 痛点 1：教材和答疑脱节

我问 AI 一个问题，它用通用知识回答，但我想让它基于我的教材回答。

DeepTutor 的解法：RAG（检索增强生成）。上传教材后，AI 的每次回答都会先检索教材内容，再基于检索结果回答。回答附带来源引用，可以追溯到原始文档的哪一页。

### 痛点 2：练习没有针对性

题库里的题是固定的，跟我的薄弱点没关系。

DeepTutor 的解法：掌握度驱动的动态出题。系统知道你对每个知识点的掌握程度（0.0~1.0），会优先出你还薄弱的知识点的题目。错题会被自动记录、分类、安排复习。

### 痛点 3：AI 答案不可追溯

AI 说这个公式是对的，但我不敢信。

DeepTutor 的解法：全链路溯源。每次工具调用（RAG 检索、网页搜索、代码执行）的结果都附带 sources 元数据，用户可以追溯到原始来源。

### 痛点 4：长期上下文丢失

上周我问过的问题，今天 AI 就不记得了。

DeepTutor 的解法：三层记忆系统。L1：原始对话日志（什么都不会丢）。L2：AI 整理的结构化笔记（按话题分组）。L3：核心摘要（用户画像、知识水平、偏好）。

### 痛点 5：AI 不会教学

AI 只会给答案，不会判断我到底懂没懂。

DeepTutor 的解法：掌握度路径（Mastery Path）。不是简单对答案，而是先诊断水平、讲解知识点、让学生用自己的话复述（费曼学习法）、出题练习、分析错误原因、在遗忘临界点安排复习。

## 5. 一次对话的完整旅程

让我们跟着学生小明的视角，看一次完整的对话是怎么运作的：

```
小明：@微积分教材 什么是链式法则？

1. 系统接收请求
   -> FastAPI 路由 -> ChatRouter

2. 准备上下文
   -> 加载微积分教材知识库
   -> 加载小明的长期记忆（知道他正在学微积分，导数掌握度 0.8）
   -> 加载历史对话摘要

3. Agent 开始工作
   -> AgenticChatPipeline 组装工具：rag + web_search + exec + ...
   -> AgentLoop 启动

4. 第一轮：AI 决定我需要查知识库
   -> 调用 rag 工具，检索链式法则
   -> 知识库返回 3 段相关内容
   -> AI 看到：链式法则是求复合函数导数的方法...

5. 第二轮：AI 决定信息够了，可以回答了
   -> 生成回答：链式法则是求复合函数导数的方法...
   -> 附带来源引用：来自《微积分教材》第 3 章第 2 节

6. 记录与学习
   -> 对话存入 Session
   -> 这条问答存入 Memory（L1）
   -> 知识点的掌握度可能更新
```

## 8. 核心设计理念

### 理念 1：Agent 自主决策，而非固定流程

传统的对话系统是用户问 -> 查知识库 -> 回答的固定流水线。DeepTutor 的 Agent 是自主决策的：它在一轮对话中可能调用 0 个工具（直接回答），也可能调用 5 个工具（查知识库 -> 搜网页 -> 跑代码 -> 画图 -> 回答），完全取决于当前问题的需要。

### 理念 2：能力叠加，而非功能堆砌

DeepTutor 的能力（Capability）系统允许在基础聊天上叠加新功能（解题、学习评估、上下文探索），而不用写新的对话流程。这叫聊天引擎 + 可插拔能力。

### 理念 3：教学法驱动，而非 AI 驱动

AI 只是工具，教学法才是灵魂。DeepTutor 的掌握度路径（Mastery Path）基于认知科学中的费曼学习法、间隔重复、错误分类等经过验证的教学理论。

### 理念 4：全链路可追溯

从 AI 回答的每一个事实，都可以追溯到知识库的哪一页、网页的哪个链接、代码的哪次运行。用户不需要信任 AI，而是可以验证 AI。

## 11. 常见问题

### Q: DeepTutor 和 ChatGPT 有什么不同？
A: ChatGPT 是通用对话 AI，DeepTutor 是教学专用的 AI 平台。它多了知识库 RAG、长期记忆、掌握度评估、学习路径、互动教材等功能。而且 DeepTutor 可以本地部署，你的教材数据不会上传到云端。

### Q: 需要什么配置才能跑起来？
A: 最低配置：Python 3.11+、一个 LLM API Key、4GB 内存。推荐配置：8GB+ 内存、GPU（用于本地 Embedding）。

### Q: 支持哪些 LLM？
A: 任何支持 OpenAI 兼容 API 的模型都可以。包括 OpenAI（GPT-4o）、Anthropic（Claude）、DeepSeek、Kimi、GLM 等。

### Q: 数据安全吗？
A: 单用户模式下所有数据存在本地。多用户模式下支持数据隔离（每个用户有独立的存储目录）。代码执行在沙箱中运行。

### Q: 能上传多大的文件？
A: 取决于你的配置。知识库支持 PDF、Word、PPT、Markdown、网页等格式，大文件会自动分块处理。

## 1.1 DeepTutor 是什么？

DeepTutor 是一个**以 AI Agent 为核心的终身个性化学习工作台**。

用一句话概括：**它不只是"AI 答题器"，而是一个能记住你、理解你、陪伴你学习的 AI 导师。**

如果把传统学习工具比作"课本+练习册"，ChatGPT 比作"随时可问的学长"，那么 DeepTutor 就是"**专属私教 + 图书馆管理员 + 学习秘书 + 研究助理**"的四合一。

### 核心特征一览

| 特征 | 说明 | 对用户的意义 |
|:---|:---|:---|
| **Agent 原生** | 从底层架构就为 Agent 设计，不是套壳 | 能力深度整合，而非拼接 |
| **能力统一** | Chat、解题、出题、研究、可视化都跑同一引擎 | 切换模式不丢上下文 |
| **上下文贯通** | 知识库、笔记本、题库、记忆在所有能力间共享 | 学习资料随处可用 |
| **模型自由** | 支持 OpenAI、Anthropic、Google、DeepSeek、本地模型等 | 不被任何厂商锁定 |
| **可扩展** | 30+ 工具、MCP 协议、社区技能市场（EduHub） | 功能可以无限扩展 |
| **可审计** | 三层记忆系统可追溯每条结论的来源 | 知道 AI 为什么这样回答 |
| **完全开源** | Apache 2.0 协议，社区驱动 | 代码透明，可自部署 |### 一个直观的类比：DeepTutor 是你的"学习操作系统"

## 1.2 解决什么痛点？

### 痛点 1：AI 对话"失忆症"

> 你告诉 ChatGPT 你正在学线性代数、第三章卡住了、你更喜欢用几何直觉理解概念。下次打开新对话，它全忘了。你又得重新解释一遍。

DeepTutor 的三层记忆系统（L1 原始轨迹 -> L2 提炼摘要 -> L3 跨域综合）让 AI 真正"记住"你。不仅记住你说过什么，还能提炼出：

- 你的学习偏好（比如"更喜欢几何直觉"）
- 你的知识薄弱点（比如"特征值计算经常出错"）
- 你近期关注的主题（比如"最近在准备期末考试"）

这些记忆是**可审计的**——你可以看到每条记忆是从哪次对话中提取的，并且可以手动编辑或删除。### 痛点 2：工具割裂——"瑞士军刀 vs 工具箱"

> 学习一个知识点，你要在 ChatGPT 问概念、在 Notion 记笔记、在 Anki 做卡片、在 Google 搜资料、在 Wolfram Alpha 解题……信息散落在五六个工具里。每次切换都打断心流。

DeepTutor 的设计哲学是"**瑞士军刀而非工具箱**"——不是把一堆工具打包在一起，而是让它们**共享同一把刀柄**（Agent 引擎）：

| 你想做的事 | 传统方式 | DeepTutor 方式 |
|:---|:---|:---|
| 问一个概念 | 打开 ChatGPT | 在 Chat 中直接问 |
| 搜索相关资料 | 打开 Google | Chat 中启用 web_search 工具 |
| 让 AI 基于你的教材回答 | 复制粘贴教材内容 | 选择 Knowledge Base，AI 自动检索 |
| 做笔记 | 打开 Notion | 让 AI 写进 Notebook |
| 生成练习题 | 手动出题 | 切换到 Deep Question 模式 |
| 写学习报告 | 打开 Word | 在 Co-Writer 中写，AI 辅助编辑 |
| 复习 | 打开 Anki | 在 Mastery Path 中系统复习 |

**关键区别**：所有这些操作共享同一个上下文。AI 知道你刚才问了什么、查了什么、笔记里写了什么——因为这都是同一个 Agent 在工作。

### 痛点 3：AI 不懂教学法

> 通用 AI 聊天只会"回答问题"，不会"教人"。它不知道你哪里没懂，不会诊断你的错误类型，更不会设计学习路径。

DeepTutor 内置了**精熟学习（Mastery Path）引擎**，这是一套完整的教学闭环：

```
诊断测试 -> 发现薄弱点 -> 针对性讲解 -> 费曼检查（你讲给AI听）
    -> 针对性练习 -> 错因诊断 -> 间隔复习 -> 通过，进入下一知识点
```

这不是"提示词工程"——每个阶段都有专门的 prompt 模板、工具策略和评估标准。Agent 在诊断阶段会使用不同的工具组合，在讲解阶段会调整语气和详细程度，在练习阶段会动态生成适合你水平的题目。### 痛点 4：知识孤岛——"你的资料，AI 不知道"

> 你有一堆 PDF 教材、论文、笔记、课件，但 AI 不知道它们的存在。每次想让 AI 基于你的资料回答，都要手动复制粘贴。

DeepTutor 的 Knowledge Base 系统让你把文档"喂"给 AI：

- 上传 PDF、DOCX、PPTX、XLSX、Markdown 等文件
- 选择文档解析引擎（Text / MinerU / Docling / markitdown / PyMuPDF4LLM）
- 选择检索引擎（LlamaIndex / PageIndex / GraphRAG / LightRAG / Obsidian）
- 支持版本化索引——更新文档后不会丢失历史版本
- 支持单个文档删除——不用整个重建

一旦建立索引，你在任何对话中都可以选择某个 Knowledge Base 作为"背景知识"，AI 会自动检索相关内容来回答问题。

### 痛点 5：封闭生态——"你只能用我们提供的"

> 大多数 AI 学习工具是封闭的：你不能换模型、不能加工具、不能自定义行为。如果厂商涨价或停止服务，你的学习数据也被锁定了。

DeepTutor 是开源的（Apache 2.0），你的数据完全在你自己手里：

- **模型自由**：接入任何 OpenAI 兼容的 API。GPT-4、Claude、Gemini、DeepSeek、Qwen、本地模型（Ollama / LM Studio / llama.cpp）都可以
- **工具自由**：30+ 内置工具 + MCP 协议（可接入任何 MCP 服务器）
- **技能自由**：Skills 系统使用开放的 Agent-Skills 格式，社区通过 EduHub 分享
- **部署自由**：PyPI 安装、Docker 部署、源码运行、CLI 模式，任你选择---

## 1.4 核心价值主张

### 一句话价值主张

> **DeepTutor = 任何模型 + 你的知识 + 教学法 + 持久记忆 + 开放生态**

### 价值拆解

**1. 模型自由（Model Freedom）**

不绑定任何一家 AI 厂商。接入 OpenAI、Anthropic、Google、DeepSeek、阿里、本地模型。模型可以随时切换，知识和记忆不丢失。这意味着：

- 你可以选最便宜的模型做简单任务，最强的模型做复杂任务
- 厂商涨价或停止服务，你换一个就行
- 敏感数据可以用本地模型，不上传云端

**2. 知识私有（Knowledge Ownership）**

你的文档、笔记、题库都在本地（或你自己的服务器上），不上传到第三方。Knowledge Base 索引是可迁移的——你可以把索引从一个服务器搬到另一个。

**3. 教学内建（Pedagogy Built-in）**

不是"AI + 提示词"，而是从架构层面支持教学法。Mastery Path 的每个阶段都有专门的 prompt 模板和工具策略。这意味着教学效果不是靠"运气好 prompt 写对了"，而是系统性地保证的。

**4. 记忆可审计（Auditable Memory）**

三层记忆不是黑盒。你可以看到 L1 的原始对话、L2 的提炼摘要、L3 的综合画像。任何一条记忆都能追溯到来源。你可以手动编辑或删除任何记忆——AI 不会"偷偷记住"你不想要的东西。

**5. 生态开放（Open Ecosystem）**

Skills 社区（EduHub）、MCP 协议、Partner 系统、IM 频道集成——DeepTutor 是一个平台，不只是应用。你可以安装社区分享的技能，也可以自己写技能并分享出去。---
