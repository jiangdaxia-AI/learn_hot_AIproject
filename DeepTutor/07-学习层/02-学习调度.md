# 学习调度器

> Understand-Anything 知识图谱: 26 节点, 25 边, 7 层
> 源码：`deeptutor/learning/mastery.py` + `deeptutor/learning/scheduler.py`
> 复杂度：`complex`

## 一句话说明

学习调度器是 DeepTutor 的"课程规划师"——它根据学生的答题历史，计算每个知识点的掌握程度，然后决定下一步该学什么、什么时候复习。就像健身房私教，根据你的体能水平调整训练计划。

## 业务价值

没有学习调度，所有学生做同样的题，效率极低：
- 已经会的反复练 → 浪费时间
- 不会的练不够 → 永远学不会
- 学过的过几天就忘 → 没有复习机制

有了学习调度：
1. **掌握度追踪**：每个知识点都有一个 0-1 的掌握度分数
2. **自适应出题**：掌握度低的点多出题，高的少出
3. **间隔重复**：在遗忘临界点自动安排复习
4. **可视化进度**：红色（薄弱）→ 黄色（一般）→ 绿色（掌握）

## 源码逐函数解析

### `compute_mastery()`（`mastery.py` 第 24 行）

**做什么**：根据答题历史计算知识点的掌握度（0-1 的分数）。

**输入**：`correctness` — 按时间顺序排列的答题结果列表，True=正确，False=错误

**输出**：0.0（完全不会）到 1.0（完全掌握）的分数

**关键设计**：

#### 1. 最近权重（Recency Weights）
```python
_RECENCY_WEIGHTS = (0.5, 0.7, 0.85, 0.95, 1.0)
```
只取最近 5 次答题，越新的权重越高：
- 最旧的那次权重 0.5
- 最新那次权重 1.0

**为什么？** 学生可能之前不会，后来学会了。最近的表现比早期的表现更能反映真实水平。

#### 2. 置信度上限（Confidence Cap）
```python
_CONFIDENCE_CAP = {1: 0.5, 2: 0.8}
```
- 只答了 1 次 → 掌握度最多 0.5（一次正确不能说明问题）
- 只答了 2 次 → 掌握度最多 0.8（两次正确还不够）
- 答了 3 次以上 → 无上限

**为什么？** 防止"侥幸正确"——学生可能蒙对了一道选择题，不能因此认为他掌握了这个知识点。

#### 计算示例

学生答了 5 次题：错、对、错、对、对（最近）
```
权重: 0.5    0.7    0.85   0.95   1.0
结果: 错     对     错     对     对
得分: 0      0.7    0      0.95   1.0
总分: 0 + 0.7 + 0 + 0.95 + 1.0 = 2.65
权重合计: 0.5 + 0.7 + 0.85 + 0.95 + 1.0 = 4.0
掌握度: 2.65 / 4.0 = 0.6625
```
由于答了 5 次，无置信度上限 → 掌握度 = 0.66（中等偏上）

### `LearningScheduler`（`scheduler.py`）

**做什么**：根据掌握度数据，调度学习计划。

**核心方法**：

#### `schedule_review()` — 安排复习

**做什么**：根据间隔重复算法，决定下次复习时间。

**算法**：基于艾宾浩斯遗忘曲线，间隔逐渐拉长：
- 第 1 次复习：1 天后
- 第 2 次复习：3 天后
- 第 3 次复习：7 天后
- 第 4 次复习：30 天后
- 第 5 次复习：90 天后

#### `get_next_question()` — 获取下一道题

**做什么**：根据掌握度，选择最需要练习的知识点。

**策略**：
1. 优先选掌握度最低的知识点
2. 如果多个知识点掌握度相同，选最近没练过的
3. 如果都练过了，随机选一个

#### `get_learning_path()` — 生成学习路径

**做什么**：生成一个有序的学习计划。

**输出**：知识点列表，按优先级排序（最需要学的排最前面）。

## 设计要点

1. **Recency-Weighted**：最近的表现比早期更重要，鼓励学生从错误中恢复
2. **Confidence Cap**：少量答题不能证明掌握，防止"侥幸正确"
3. **间隔重复**：基于遗忘曲线，在最佳时机安排复习
4. **简单可替换**：`compute_mastery()` 是纯函数，想换算法只改这一个函数即可

### 掌握度计算详解

`compute_mastery()` 是 DeepTutor 教学算法的核心，它决定了"学生对某个知识点掌握到什么程度"。

**算法原理**：

输入：一个知识点的答题历史（正确/错误列表）
输出：0~1 的掌握度分数

**递进权重（Recency Weight）**：

最近一次答题最重要，越早的答题权重越低：

| 答题次序 | 权重 | 含义 |
|----------|------|------|
| 第 1 次（最早） | 0.5 | 参考价值低 |
| 第 2 次 | 0.7 | 有一定参考 |
| 第 3 次 | 0.85 | 参考价值较高 |
| 第 4 次 | 0.95 | 接近最新 |
| 第 5 次（最新） | 1.0 | 最重要 |

**置信度上限（Confidence Cap）**：

少量答题不能证明"掌握"。系统设置了上限：

| 答题次数 | 掌握度上限 | 原因 |
|----------|-----------|------|
| 1 次 | 0.5 | 一次正确可能是运气 |
| 2 次 | 0.8 | 两次正确提高了信心 |
| 3 次及以上 | 1.0 | 足够证据了 |

**举例**：
- 学生答了 1 次，正确 → 掌握度 = min(1.0×1.0/1.0, 0.5) = 0.5
- 学生答了 2 次，都正确 → 掌握度 = min((0.7×1.0+1.0×1.0)/(0.7+1.0), 0.8) ≈ 0.8
- 学生答了 3 次，正确、错误、正确 → 掌握度 = (0.5×1.0+0.7×0+0.85×1.0)/(0.5+0.7+0.85) ≈ 0.66

### 间隔重复调度

DeepTutor 的学习调度器实现了间隔重复（Spaced Repetition）算法：

**核心理念**：在即将遗忘的时候复习，记忆效果最好。

**调度策略**：

1. **新知识点**：学习后 1 天复习
2. **第一次复习正确**：3 天后再次复习
3. **第二次复习正确**：7 天后再次复习
4. **第三次复习正确**：14 天后再次复习
5. **后续**：按指数增长间隔（×2）

**复习失败的处理**：
- 如果复习时答错，间隔重置为 1 天
- 连续失败 3 次，标记为"需要重新学习"
- 系统会为该知识点生成新的学习材料

### 学习路径规划

**自适应学习路径**：

1. **诊断阶段**：通过初始测试评估学生水平
2. **规划阶段**：根据诊断结果生成学习路径
   - 优先学习前置知识点
   - 跳过已掌握的知识点
   - 集中攻克薄弱点
3. **执行阶段**：按路径顺序推送学习内容
4. **调整阶段**：根据学习进度动态调整路径

**学习路径的优先级**：
1. 前置依赖（必须先学 A 才能学 B）
2. 掌握度（低掌握度的优先）
3. 遗忘风险（快忘记的优先复习）
4. 学习目标（与考试/目标相关的优先）

### 学习数据追踪

**追踪的数据维度**：
- 每个知识点的答题历史
- 每次答题的正确性和耗时
- 复习间隔和效果
- 学习时长和频率
- 薄弱点变化趋势

**数据用途**：
- 生成学习报告
- 优化调度算法
- 个性化推荐
- 教师监控学生进度



### 学习调度的实际应用

**场景1：考前复习**
- 系统检测到期末考试临近
- 自动生成复习计划：优先复习掌握度低、遗忘风险高的知识点
- 每天推送复习题目
- 考前一天进行模拟测试

**场景2：新知识点学习**
- 学生学习新章节
- 系统按"预习→学习→练习→复习"的节奏调度
- 学习后 1 天、3 天、7 天分别推送复习
- 连续 3 次正确后标记为"已掌握"

**场景3：补救学习**
- 学生某个知识点连续答错 3 次
- 系统标记为"需要重新学习"
- 生成新的学习材料（简化版、图解版）
- 降低练习难度，增加提示
- 逐步提高难度直到掌握

### 调度算法的可配置性

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 初始间隔 | 1 天 | 新学后多久第一次复习 |

### 学习调度的技术实现

**调度器架构**：
- `LearningScheduler`：主调度器，管理学习计划
- `MasteryTracker`：掌握度追踪器，实时更新掌握度
- `SpacedRepetitionEngine`：间隔重复引擎，计算复习时间
- `PathPlanner`：路径规划器，生成学习路径

**调度算法伪代码**：
```
def schedule(user_id, days_ahead=7):
    plan = []
    points = get_weakest_points(user_id, limit=10)
    for point in points:
        if point.is_due_for_review():
            plan.append(generate_review_task(point))
        elif point.mastery < 0.5:
            plan.append(generate_learning_task(point))
    return sort_by_priority(plan)
```

**优先级排序规则**：
1. 即将遗忘的（最高优先级）
2. 掌握度 < 0.3 的
3. 前置依赖的
4. 与考试目标相关的
5. 掌握度 0.3-0.5 的


### 总结

DeepTutor 的学习调度系统是一个智能的教学规划引擎。它综合考虑了掌握度、遗忘曲线、知识点依赖关系和学习目标，为每个学生生成个性化的学习计划。核心理念是"在对的时间复习对的内容"，最大化学习效率。

**关键设计**：
1. 递进权重让最近的表现更重要
2. 置信度上限防止"虚假掌握"
3. 间隔重复基于遗忘曲线科学设计
4. 学习路径动态调整，适应学生变化
