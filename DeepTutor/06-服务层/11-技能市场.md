# 11 — 技能市场（Skill Hub）

> **源码位置**：`deeptutor/services/skill/`（5 个文件）
> **阅读对象**：产品经理 / 运营 / 非技术人员
> **目标**：看懂 DeepTutor 如何从外部技能市场导入和安装技能

---

## 一句话概括

技能市场是 DeepTutor 的"技能商店"。用户可以从外部注册中心（如 ClawHub）下载和安装技能包，让 DeepTutor 获得新的能力——比如"苏格拉底式教学"、"数学解题助手"等。

---

## 生活化比喻

> 技能市场就像**手机应用商店里的"技能包"**：
> - 手机自带一些基础功能
> - 但你可以从应用商店下载"摄影大师"技能包，获得专业拍照能力
> - 每个技能包是一个 SKILL.md 文件 + 可选的辅助文件
> - 安装后，DeepTutor 就能使用这个技能

---

## 一、整体架构

| 文件 | 角色比喻 | 职责 |
|------|----------|------|
| `hub.py` | 应用商店 | 从外部注册中心获取技能包 |
| `service.py` | 安装管理器 | 安装、卸载、更新技能 |
| `taxonomy.py` | 技能分类 | 按类别组织技能（教学、解题、可视化等） |
| `credentials.py` | 权限管理 | 管理技能所需的 API Key 等凭证 |

---

## 二、技能安装流程

```
用户在技能市场搜索技能
  │
  ▼
hub.py 从注册中心获取技能包
  │
  ▼
安全检查：验证技能包是否安全
  │
  ├─ suspicious → 拒绝安装
  │
  └─ safe → 下载并解压技能包
       │
       ▼
    service.py 安装技能到本地
       │
       ▼
    技能立即可用
```

---

## 三、对产品/运营的一句话总结

> 技能市场让 DeepTutor 的能力可以无限扩展。用户不需要等官方更新，直接从技能市场下载需要的技能包，就能让 DeepTutor 获得新能力。
