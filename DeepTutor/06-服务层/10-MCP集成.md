# 10 — MCP 集成（外部工具接入）

> **源码位置**：`deeptutor/services/mcp/`（6 个文件）
> **阅读对象**：产品经理 / 运营 / 非技术人员
> **目标**：看懂 DeepTutor 如何接入外部工具（通过 MCP 协议），让 AI 能调用更多能力

---

## 一句话概括

MCP（Model Context Protocol，模型上下文协议）是 DeepTutor 的"万能插座"。通过 MCP，DeepTutor 可以连接任何支持 MCP 的外部工具服务器——比如数据库查询工具、文件管理工具、第三方 API 工具——让 AI 的能力无限扩展。

---

## 生活化比喻

> MCP 就像**手机上的应用商店**：
> - 手机（DeepTutor）自带一些基础功能（拍照、打电话）
> - 但你可以从应用商店下载更多 App（MCP 工具），扩展手机的能力
> - 每个 App 有自己的功能（数据库查询、文件管理、API 调用）
> - 安装后，AI 就能直接调用这些 App 的功能

---

## 一、整体架构

| 文件 | 角色比喻 | 职责 |
|------|----------|------|
| `manager.py` | 应用商店管理员 | 统一管理所有 MCP 服务器连接的生命周期 |
| `config.py` | 应用配置 | 每个 MCP 服务器的连接参数 |
| `network.py` | 网络层 | 处理 MCP 的网络通信 |
| `pageindex_server.py` | 页面索引服务 | 内置的 MCP 服务器，提供页面索引功能 |
| `session_state.py` | 会话状态 | 管理 MCP 连接的会话状态 |

---

## 二、核心流程

```
用户安装 MCP 工具
  │
  ▼
manager.py 创建连接任务
  │
  ▼
连接建立 → 工具注册到 ToolRegistry
  │
  ▼
AI 调用工具 → 通过 MCP 协议发送请求
  │
  ▼
外部工具执行 → 返回结果给 AI
```

---

## 三、对产品/运营的一句话总结

> MCP 让 DeepTutor 可以接入无限的外部工具。就像一个手机可以安装无限的 App，DeepTutor 可以通过 MCP 连接任何外部服务，让 AI 的能力无限扩展。
