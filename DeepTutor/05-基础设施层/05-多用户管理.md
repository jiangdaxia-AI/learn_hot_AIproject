# 多用户管理（Multi-User）

> **源码位置**：`deeptutor/multi_user/`（13 个文件）
> **阅读对象**：产品经理 / 运营

---

## 一句话概括

多用户管理让 DeepTutor 支持多个用户同时使用——每个用户有自己的学习进度、知识库、对话历史，互不干扰。就像学校里的"档案柜"——每个学生一个档案夹。

## 生活化比喻

> 就像图书馆的借阅系统——每个读者有自己的借书卡（用户账号），有自己的借阅记录（学习历史），有自己的预约（学习计划），互不干扰。

## 核心模块

| 文件 | 职责 |
|------|------|
| `auth.py` | 用户认证：登录、注册、密码管理 |
| `profile.py` | 用户档案：学习偏好、语言设置 |
| `session.py` | 会话管理：每个用户的对话历史 |
| `isolation.py` | 数据隔离：确保用户之间数据不泄露 |

## 对产品/运营的一句话总结

> 多用户管理让 DeepTutor 可以同时服务多个学生，每个学生看到的内容完全独立，就像每个人有自己的专属家教。
