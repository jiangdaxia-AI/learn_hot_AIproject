# 运行时管理（Runtime）

> **源码位置**：`deeptutor/runtime/`（13 个文件）
> **阅读对象**：产品经理 / 运营

---

## 一句话概括

运行时管理负责 DeepTutor 的启动、运行模式切换、聊天编排。就像汽车的"点火系统"——决定 DeepTutor 以什么模式运行（命令行、Web 服务、桌面应用），以及如何启动和停止。

## 生活化比喻

> 就像汽车的钥匙和仪表盘——你转动钥匙（启动），选择驾驶模式（P/R/N/D），汽车就能正常工作。

## 核心模块

| 文件 | 职责 |
|------|------|
| `mode.py` | 运行模式：CLI / Server / Desktop |
| `launcher.py` | 启动器：初始化所有服务并启动 |
| `orchestrator.py` | 聊天编排器：协调 Agent 和 UI 之间的通信 |
| `bootstrap/` | 启动引导：加载内置能力、初始化配置 |
| `home.py` | 数据目录管理：用户数据存储位置 |

## 对产品/运营的一句话总结

> 运行时管理让 DeepTutor 可以在不同环境下运行——命令行、Web 服务、桌面应用，用户只需切换模式即可。
