# 知识库管理（Knowledge）

> **源码位置**：`deeptutor/knowledge/`（7 个文件）
> **阅读对象**：产品经理 / 运营

---

## 一句话概括

知识库是 DeepTutor 的"参考资料库"。用户可以上传教材、课件、笔记等文档，DeepTutor 从中提取知识，用于回答问题和出题。就像老师的"备课资料"——上课前先准备好参考资料。

## 生活化比喻

> 就像给家教老师一本教材——老师先看教材（知识库），然后根据教材内容来教学生。没有教材，老师只能凭记忆教学；有了教材，教学更准确、更系统。

## 核心能力

| 能力 | 说明 |
|------|------|
| 文档上传 | 支持 PDF、DOCX、PPTX、图片等格式 |
| 知识提取 | 自动从文档中提取关键知识点 |
| 语义搜索 | 根据问题找到最相关的知识片段 |
| 知识图谱 | 构建知识点之间的关联关系 |

## 对产品/运营的一句话总结

> 知识库让 DeepTutor 的教学有"据"可依——用户上传教材后，AI 的教学内容更准确、更系统。
