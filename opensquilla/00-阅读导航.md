## 推荐阅读路径

### 🚀 如果你只有 10 分钟

```
00 阅读导航 (本文) → 01 系统全景 → 04 流程追踪 → 03-02 引擎模块
```

看完这 4 个文件，你能理解：OpenSquilla 是什么、怎么用、核心流程、引擎怎么工作。

### 📋 如果你是产品经理（写 PRD）

```
00 → 01 → 04 → 03-02 → 03-07 → 03-08 → 05 → 06
```

重点看：系统全景（了解产品定位和竞品）、流程追踪（理解用户场景）、引擎和通道（核心技术细节）、数据模型（PRD 的数据结构部分）、附录（术语表）。

### 🏗️ 如果你是架构师

```
00 → 02 → 03-01 → 03-02 → 03-03 → 03-06 → 03-08 → 03-09 → 05
```

重点看：架构总览（分层和依赖）、网关和引擎（核心入口和大脑）、提供商和路由器（LLM 调用和调度）、沙箱和调度（安全和高可用）、数据模型。

### 🧑‍💻 如果你是开发者（接手代码）

```
00 → 02 → 03-01 → 03-02 → 03-03 → 03-04 → 03-07 → 03-10 → 03-11 → 03-12 → 06
```

重点看：架构总览、网关和引擎（入口和核心循环）、提供商和工具（如何调用 LLM 和执行操作）、通道（如何接入消息平台）、引导和可观测性（如何配置和调试）、MCP（外部集成）、源码速查表。
