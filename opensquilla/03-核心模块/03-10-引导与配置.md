## 定位

引导模块是 OpenSquilla 的**一键安装向导**。用户首次运行 `opensquilla onboard` 时，引导模块一步步帮用户配置 AI 提供商、选择模型、设置通道，把复杂的配置过程变成交互式问答。

> 来源：onboarding/setup_engine.py:96 SetupEngine 类

## 生活化比喻

> 引导模块像**新手机的开机向导**。你拿到新手机，它一步步带你选语言、连 Wi-Fi、登录账号、设置指纹。你不用知道背后的技术细节，跟着点就行。

## 一、SetupEngine 架构（6 步引导流程）

SetupEngine (onboarding/setup_engine.py:96) 的完整引导流程：

```
步骤 1：提供商选择
  → 列出支持的 AI 提供商（Anthropic/OpenAI/DeepSeek/Ollama...）
  → 用户选择 → 输入 API Key
  → 源码：onboarding/mutations.py provider_upsert()

步骤 2：模型配置
  → 为每个难度层级（C0/C1/C2/C3）选择默认模型
  → 源码：onboarding/mutations.py tier_config()

步骤 3：路由器配置
  → 配置 SquillaRouter 的模型目录和版本
  → 源码：setup_engine.py _apply_router()

步骤 4：通道配置（可选）
  → 配置飞书/Slack/Telegram 等通道
  → 源码：onboarding/mutations.py channel_upsert()

步骤 5：搜索配置（可选）
  → 配置网页搜索提供商（Brave/Tavily/DuckDuckGo）
  → 源码：onboarding/mutations.py search_config()

步骤 6：持久化配置
  → 写入 opensquilla.toml 配置文件
  → 源码：onboarding/config_store.py persist_config()
```

> 来源：onboarding/flow.py 完整引导流程、onboarding/setup_engine.py:96-200
