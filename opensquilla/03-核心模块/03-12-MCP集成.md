# 03-12 · MCP 集成 (Model Context Protocol) — 深度剖析

> **文件数**：mcp 5 + mcp_server 2 = 7 个文件 | **核心类**：MCPServerConfig (mcp/types.py:10) | **codegraph blast radius**：19 callers | **服务端**：create_mcp_server (mcp_server/server.py:10)

---

## 定位

MCP 集成是 OpenSquilla 的"万能转接头"。通过 MCP 协议，OpenSquilla 可以连接任何支持 MCP 的外部工具服务器——比如数据库查询工具、文件管理工具、第三方 API 工具——无缝扩展 Agent 的能力。

> 来源：mcp/types.py:10 MCPServerConfig、mcp_server/server.py:10 create_mcp_server

---

## 生活化比喻

> MCP 像**USB-C 扩展坞**。你的电脑只有一个 USB-C 口，但通过扩展坞可以接显示器、键盘、鼠标、网线。MCP 就是 AI Agent 的"扩展坞协议"——OpenSquilla 通过 MCP 连接各种外部工具。

---

## 一、MCP 双角色架构

OpenSquilla 同时扮演 MCP 客户端和 MCP 服务器：

```
┌──────────────────────────────────────────────┐
│              OpenSquilla                      │
│                                              │
│  ┌──────────────────────┐                    │
│  │ MCP 客户端 (mcp/)     │                    │
│  │ • 连接外部 MCP 服务器  │  ←─── 外部 MCP 服务器
│  │ • 发现工具列表         │      (数据库/文件系统/API)
│  │ • 调用远程工具         │                    │
│  └──────────────────────┘                    │
│                                              │
│  ┌──────────────────────┐                    │
│  │ MCP 服务器 (mcp_server/) │                │
│  │ • 暴露 OpenSquilla 工具 │  → 外部 MCP 客户端
│  │ • stdio/SSE 传输       │     (其他 AI 应用)
│  └──────────────────────┘                    │
└──────────────────────────────────────────────┘
```

---

## 二、MCP 客户端 — 连接外部工具

MCP 客户端负责发现和管理外部 MCP 服务器：

| 组件 | 文件 | 职责 |
|------|------|------|
| MCPServerConfig | mcp/types.py:10 | 服务器配置（command/args/env/url） |
| MCPClient | mcp/client.py | 管理与一个 MCP 服务器的连接 |
| MCPDiscovery | mcp/discovery.py | 发现外部 MCP 服务器 |
| MCPSSEClient | mcp/sse.py | SSE 传输客户端 |
| MCPStdioClient | mcp/stdio.py | stdio 传输客户端 |

生命周期：connect → list_tools → call_tool → close

> 来源：mcp/client.py, mcp/discovery.py

---

## 三、MCP 服务器 — 暴露 OpenSquilla 工具

`create_mcp_server()` (mcp_server/server.py:10) 将 OpenSquilla 的工具注册表暴露为 MCP 服务器，让其他 AI 应用可以调用。

支持两种传输方式：
- **stdio**：标准输入输出（适合本地进程间通信）
- **SSE**：Server-Sent Events（适合 HTTP 远程调用）

> 来源：mcp_server/server.py:10-50

---

## 四、配置结构

MCPServerConfig (mcp/types.py:10) 的核心字段：

| 字段 | 说明 |
|------|------|
| name | 服务器名称 |
| command | 启动命令 |
| args | 命令参数 |
| env | 环境变量 |
| url | SSE 端点 URL |
| enabled | 是否启用 |

> 来源：mcp/types.py:10-30
