## 定位

网关是整个 OpenSquilla 的**唯一入口**。所有外部请求——无论是 CLI 命令、Web 控制台点击、还是飞书消息——都必须经过网关。它不是一个简单的 HTTP 路由，而是一个完整的应用工厂，接收 20+ 个依赖注入参数。

> 来源：`gateway/app.py` L56 `create_gateway_app` 函数签名包含 20+ 个参数（session_manager, provider_selector, tool_registry, channel_manager, cron_scheduler, turn_runner 等）

---

## 生活化比喻

> 网关像一个**五星级酒店的前台大堂**。每个客人的请求都要经过 5 道安检（中间件管道），然后大堂经理（RPC 调度器）根据需求分派到不同的服务员。如果要动保险箱（危险操作），前台会让你签字确认（审批队列）。

## 二、中间件管道（5 层）

每个 HTTP 请求经过 5 层中间件：

```
请求 →
  1. SecurityHeadersMiddleware  (安全头：HSTS, CSP, X-Frame-Options)
  2. RateLimitMiddleware        (限流：基于 IP/用户的速率限制)
  3. AuthMiddleware             (认证：Bearer Token / API Key 校验)
  4. CORSMiddleware             (跨域：CORS 白名单)
  5. origin_guard               (同源校验：防止 CSRF 攻击)
→ 业务处理
```

| 中间件 | 文件 | 职责 | 源码 |
|--------|------|------|------|
| SecurityHeaders | `gateway/middleware.py` | 添加安全 HTTP 头 | `gateway/app.py` L16 |
| RateLimit | `gateway/middleware.py` | 限制请求频率 | `gateway/app.py` L17 |
| Auth | `gateway/middleware.py` | 验证请求身份 | `gateway/app.py` L18 |
| CORS | Starlette 内置 | 跨域资源共享 | `gateway/app.py` L19 |
| OriginGuard | `gateway/origin_guard.py` | 同源校验 | `gateway/app.py` L25-L29 |

## 四、RPC 调度器 — 统一请求分发

RPC 调度器（`gateway/rpc.py`）是网关的核心路由机制：

```
POST /api/rpc {method: "chat.send", params: {...}}
│
▼
┌─ RPC 调度器 ────────────────────────────────────────┐
│ 1. 解析 method 名称                                  │
│ 2. 查找注册的 handler                                │
│ 3. 参数校验（Pydantic）                              │
│ 4. 调用 handler                                     │
│ 5. 返回 JSON-RPC 格式响应                            │
│                                                      │
│ 错误码映射：                                          │
│   INVALID_REQUEST → 400                              │
│   UNAUTHORIZED → 403                                 │
│   NOT_FOUND → 404                                    │
│   SESSION_CONFLICT → 409                             │
│   QUEUE_FULL → 429                                   │
│   UNAVAILABLE → 503                                  │
└──────────────────────────────────────────────────────┘
```

> 来源：`gateway/app.py` L86-L114 `_rpc_status_code` 函数

## 六、审批队列系统

危险操作进入审批队列，等待人工确认：

```
┌─ 审批流程 ───────────────────────────────────────┐
│ 1. Agent 请求执行危险操作                          │
│ 2. 工具处理器检查权限策略                           │
│ 3. 如需审批 → 加入 approval_queue                 │
│ 4. 通知用户（WebSocket 推送）                      │
│ 5. 用户确认/拒绝                                   │
│ 6. 确认后执行，拒绝后返回错误                       │
│                                                    │
│ 审批项包含：                                        │
│   - 操作类型（shell 命令/文件写入/网络请求）          │
│   - 操作详情（完整命令/路径/URL）                   │
│   - 风险等级（低/中/高）                            │
│   - 时间戳                                         │
└────────────────────────────────────────────────────┘
```

> 来源：`gateway/approval_queue.py`、`gateway/approval_events.py`、`gateway/approval_notify.py`
