## 5.1 实体关系总览

核心数据模型之间的引用关系（→ 表示"引用/依赖"）：

```
GatewayConfig (gateway/config.py)
  ├──→ LlmProviderProfile[] (提供商配置)
  │     ├──→ ProviderConfig (选择器配置)
  │     └──→ Credential (API Key)
  ├──→ ConfiguredChannelEntry[] (通道配置)
  │     └──→ ManagedChannel (运行时适配器)
  └──→ SandboxPolicy (沙箱策略)

SessionManager (session/manager.py:201)
  ├──→ SessionNode (会话节点)
  │     ├── session_key, session_id, agent_id
  │     ├── status: SessionStatus (RUNNING/DONE/ERROR)
  │     ├── chat_type: ChatType (DIRECT/GROUP/THREAD)
  │     ├── epoch, input_tokens, output_tokens
  │     └──→ SessionSummary (会话摘要)
  ├──→ CompactionConfig (压缩配置)
  └──→ AgentTaskRecord (代理任务记录)

Agent (engine/agent.py:1662)
  ├──→ LLMProvider (提供商协议)
  ├──→ AgentConfig (代理配置)
  ├──→ ToolRegistry (工具注册表)
  ├──→ SubagentManager (子代理管理)
  │     ├──→ SubagentSpec (子代理参数)
  │     ├──→ SubagentHandle (子代理引用)
  │     └──→ SubagentRegistry (子代理注册表)
  ├──→ ContextBudgetGovernor (预算管理)
  │     └──→ ContextBudgetSnapshot (预算快照)
  ├──→ FallbackPolicy (回退策略)
  ├──→ FinalizeEvidenceTracker (证据门控)
  ├──→ PostWriteConvergenceTracker (写入收敛)
  └──→ CompactionConfig (压缩配置)

SchedulerEngine (scheduler/engine.py:46)
  ├──→ CronJob (定时任务)
  │     ├── schedule: ScheduleKind (cron/every/at)
  │     ├── job_kind: JobKind (reminder/system_event/agent_turn)
  │     └── session_target: SessionTarget (main/isolated/current/session)
  ├──→ JobStore (任务持久化)
  ├──→ SchedulerTimer (定时器)
  └──→ SessionReaper (会话清理)
```

## 5.7 存储结构

| 数据类型 | 存储介质 | 格式 | 说明 |
|----------|---------|------|------|
| 会话数据 | SQLite | SessionNode 表 | 会话元数据, 状态, token 统计 |
| 会话消息 | SQLite + 文件系统 | JSON 序列化 | 完整对话历史 |
| 记忆数据 | SQLite + sqlite-vec | 向量嵌入 | 长期记忆, 语义搜索 |
| 定时任务 | SQLite | CronJob 表 | 任务定义, 调度规则 |
| 配置文件 | TOML 文件 | opensquilla.toml | 网关配置, 通道配置, 提供商配置 |
| 代理配置 | TOML 文件 | agents.toml | 多代理定义 |
| 技能文件 | Markdown 文件 | SKILL.md | 6 层优先级体系 |
| 路由模型 | 二进制文件 | lgbm_model.bin + features/ | LightGBM 模型文件 |
| 诊断数据 | 文件系统 | JSON/日志 | 运行时诊断 |
