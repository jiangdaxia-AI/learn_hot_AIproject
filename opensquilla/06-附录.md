## 6.1 术语表（中英对照）

| 术语 | 英文 | 白话解释 |
|------|------|---------|
| 代理 | Agent | 一个 AI 对话实体，有自己的配置和记忆 |
| 会话 | Session | 一次完整的对话，包含所有消息轮次 |
| 轮次 | Turn | 用户发一次消息 + AI 回复一次 = 一个 turn |
| 工具 | Tool | AI 可以调用的函数（如执行命令、搜索网页） |
| 技能 | Skill | 多个工具调用的组合，可复用的工作流 |
| 网关 | Gateway | 系统的 HTTP 入口，所有请求先到这里 |
| 引擎 | Engine | AI 的大脑，控制思考→行动的循环 |
| 提供商 | Provider | AI 模型的服务商（OpenAI/Anthropic 等） |
| 路由器 | Router | 判断任务难度，选择最合适的模型 |
| 通道 | Channel | 消息平台（飞书/Slack/Telegram 等） |
| 沙箱 | Sandbox | 隔离执行环境，防止 AI 搞破坏 |
| 压缩 | Compaction | 把长对话压缩成摘要，节省 token |
| 记忆 | Memory | AI 的长期记忆，跨对话的持久化信息 |
| 审批 | Approval | 危险操作需要人工确认 |
| 回退 | Fallback | 主模型挂了，自动切换到备用模型 |
| 定时任务 | Cron Job | 按时间表自动执行的任务 |
| 子代理 | Subagent | Agent 生成的子 Agent，处理子任务 |
| 嵌入 | Embedding | 把文本转成向量，用于语义搜索 |
| 上下文 | Context | 发给 LLM 的完整信息（提示词+历史+工具） |
| 令牌 | Token | LLM 处理文本的最小单位（约 0.75 个英文单词） |
| 事件 | Event | Agent 状态变化时发出的通知 |
| 中间件 | Middleware | 请求处理管道中的拦截器 |
| 路由 | Route | URL 路径到处理函数的映射 |
| 依赖注入 | Dependency Injection | 把组件需要的依赖从外部传入 |
| 数据飞轮 | Data Flywheel | 从使用数据中学习，越用越好的闭环 |
| 指数退避 | Exponential Backoff | 重试间隔越来越长（1s→2s→4s→...） |
| 门控 | Gate | 操作前/后的安全检查点 |
| 协议 | Protocol | 组件之间约定的接口规范 |
| 适配器 | Adapter | 把一种格式转换成另一种格式的转换器 |
| 注册表 | Registry | 管理所有已注册组件的中央目录 |
| 管线 | Pipeline | 多个处理步骤串起来的流程 |

## 6.4 复刻 PRD 指南

### MVP 优先级

| 优先级 | 模块 | 原因 |
|--------|------|------|
| P0 | Gateway + Engine + Provider | 核心对话能力 |
| P0 | Tools (exec_command, read_file, web_search) | 基础工具能力 |
| P1 | SquillaRouter | 成本优化 |
| P1 | Channels (1-2 个) | 多渠道接入 |
| P2 | Memory | 长期记忆 |
| P2 | Sandbox | 安全执行 |
| P2 | Skills | 可复用工作流 |
| P3 | Scheduler (Cron) | 定时任务 |
| P3 | More Channels | 更多平台 |
| P3 | Ensemble | 多模型组合 |

### 推荐技术栈

| 层 | 推荐 | 原因 |
|----|------|------|
| 后端 | Python 3.12+ + Starlette | 异步支持好，生态丰富 |
| LLM 协议 | 统一 Provider 抽象层 | 切换模型零成本 |
| 数据库 | SQLite + sqlite-vec | 零配置，本地向量搜索 |
| 前端 | Vue 3 + TypeScript + Vite | 组件化，开发效率高 |
| 桌面 | Electron | 跨平台 |
| 路由 | LightGBM | 轻量、快速、适合表格特征 |
| 沙箱 | Bubblewrap(Linux) / Seatbelt(macOS) | OS 原生安全 |
| 构建 | uv (Python) / npm (前端) | 快速依赖管理 |
