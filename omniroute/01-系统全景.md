## 1.1 一句话定位

**OmniRoute 是一个 AI 路由器**——它像一个"万能遥控器"，一个遥控器控制所有 AI 服务（OpenAI、Claude、Gemini 等 160+ 家），自动选最便宜最好用的，坏了一个自动换另一个。

> 来源：package.json description

---

## 1.2 解决什么问题

| 痛点 | OmniRoute 的方案 | 大白话 |
|------|-----------------|--------|
| AI 服务太多，每个都要单独注册 | 一个账号管理 160+ 家 | 一个遥控器控制所有电视 |
| 不知道选哪个 AI 最划算 | Combo 自动选择最优提供商 | 自动比价，选最便宜的 |
| AI 服务突然不可用 | 自动故障转移 | 这家的饭卖完了，自动去隔壁 |
| API 调用太费钱 | RTK+Caveman 双引擎压缩 | 压缩打包，节省运费 |
| 想在免费工具里用自己的 API Key | MITM 透明代理 | 拦截工具请求，替换成自己的 Key |
| 免费额度被回收 | 配额自动 Ping 保活 | 定时打卡，保持活跃 |

> 来源：package.json description、codegraph 源码分析

## 1.3 产品形态

| 形态 | 技术 | 大白话 |
|------|------|--------|
| 命令行工具 | Node.js CLI (Commander) | 终端里敲命令使用 |
| Web 仪表盘 | Next.js + React | 浏览器里点点点管理 |
| 桌面应用 | Electron | 双击图标就用 |
| API 接口 | OpenAI 兼容 API | 用 OpenAI 的格式调用，背后是 OmniRoute |

## 1.4 竞品对比

| 维度 | OmniRoute | OpenAI Router | LiteLLM |
|------|----------|---------------|---------|
| 接入方式 | API Key + OAuth + Web 客户端 | 仅 API Key | 仅 API Key |
| 提供商数量 | 160+ | ~50 | ~100 |
| 压缩引擎 | RTK + Caveman 双引擎 | 无 | 无 |
| 免费额度利用 | 14 个 Web 客户端执行器 | 无 | 无 |
| MITM 代理 | 14+ 目标透明拦截 | 无 | 无 |
| 桌面应用 | macOS + Windows + Linux | 无 | 无 |
| 开源 | 是（GitHub） | 部分 | 是 |

> 来源：各项目公开文档对比
