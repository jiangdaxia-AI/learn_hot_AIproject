## 2.1 5 层架构（大白话版）

```
┌─────────────────────────────────────────────────────────┐
│ 第 1 层：用户入口（User Surface）                        │
│ 命令行工具 │ Web 仪表盘 │ 桌面应用 │ API 接口            │
│ 大白话：不管从哪个门进来，内部服务都一样                   │
├─────────────────────────────────────────────────────────┤
│ 第 2 层：网关层（Gateway）                                │
│ Next.js Route Handlers + Express 5 服务器                 │
│ 200+ API 端点 │ 认证 │ 限流 │ 日志                       │
│ 大白话：前台接待，检查身份，登记来访                       │
├─────────────────────────────────────────────────────────┤
│ 第 3 层：代理引擎层（Proxy Engine）                        │
│ SSE 流式代理 │ AuthZ Pipeline │ proxyFetch 捕获          │
│ 压缩注入（RTK + Caveman）│ Combo 选择                     │
│ 大白话：分拣中心，拆包检查，选最优快递公司                  │
├─────────────────────────────────────────────────────────┤
│ 第 4 层：能力层（Capabilities）                           │
│ 提供商适配 160+ │ 压缩引擎 │ 故障转移 │ MITM 代理         │
│ 大白话：各种专业工具，各司其职                             │
├─────────────────────────────────────────────────────────┤
│ 第 5 层：基础设施层（Infrastructure）                      │
│ SQLite 数据库 │ 加密存储 │ 文件系统 │ 日志                │
│ 大白话：档案室、保险柜、监控录像                           │
└─────────────────────────────────────────────────────────┘
```

> 来源：knowledge-graph.json architecture.layers

## 2.2 核心模块速览

| 模块 | 文件数 | 一句话 | 类比 |
|------|--------|--------|------|
| 路由引擎 | 50+ | 接收请求→选最优提供商→返回结果 | 快递中转站 |
| 压缩系统 | 30+ | 压缩对话内容，节省 token 费用 | 真空打包机 |
| 故障转移 | 20+ | 提供商挂了自动切换 | 外卖平台调度 |
| MITM 代理 | 15+ | 拦截 AI 工具请求，用自己 Key | 航班中转 |
| 仪表盘 | 100+ | Web 管理控制台 | 中控面板 |
| 认证系统 | 20+ | 5 种认证方式 | 门禁系统 |
| 配额管理 | 10+ | 监控用量，防止超支 | 消费提醒 |
| 护栏系统 | 10+ | 速率限制、内容过滤 | 安保监控 |
