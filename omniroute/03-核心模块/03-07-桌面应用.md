# 03-07 · 桌面应用 (Electron) — 深度剖析

> **技术栈**：Electron + Node.js | **文件**：electron/main.js (713+ 行) | **IPC 通道**：15+ 个 | **平台**：macOS + Windows + Linux

---

## 定位

桌面应用是 OmniRoute 的"一键安装版"。用户不需要打开终端敲命令，双击图标就能用——就像微信、QQ 一样。它内置了本地服务器，后台静默运行。

> 来源：electron/main.js、electron/package.json

---

## 生活化比喻

> 桌面应用像**智能电视的遥控器 App**。电视本体（OmniRoute 服务器）在后台运行，但你不需要碰它——你只需要在手机 App（桌面应用）上点按钮，就能控制所有功能。App 还负责自动更新电视的系统（自动更新）。

## 一、核心功能（6 项）

| 功能 | 大白话 | 实现方式 |
|------|--------|---------|
| 一键启动 | 双击图标，自动启动本地服务 | electron/main.js startNextServer() |
| 系统托盘 | 最小化到菜单栏，后台运行 | createTray() 创建托盘图标 |
| 自动更新 | 检测新版本，自动下载安装 | checkForUpdates() + downloadUpdate() + installUpdate() |
| 开机自启 | 电脑开机自动启动 | enableLinuxDesktopAutostart() |
| 端口管理 | 自动选择可用端口，避免冲突 | changePort() + serverPort 变量 |
| 窗口管理 | 1400×900 默认窗口，最小 1024×700 | BrowserWindow 配置 |

> 来源：electron/main.js 的 setupIpcHandlers() 调用列表

## 二、IPC 通信（15+ 个通道）

桌面应用通过 IPC（进程间通信）在前端（网页）和主进程（Electron）之间传递消息：

| IPC 通道 | 方向 | 大白话 |
|----------|------|--------|
| getServerUrl | 前端→主进程 | 前端问"服务器地址是什么？" |
| getActiveProvider | 前端→主进程 | 前端问"当前用的是哪个提供商？" |
| startLogin | 前端→主进程 | 用户点击登录，触发 OAuth 流程 |
| cancel | 前端→主进程 | 取消当前操作 |
| checkForUpdates | 主进程→服务器 | 检查是否有新版本 |
| downloadUpdate | 主进程→服务器 | 下载更新包 |
| installUpdate | 主进程→用户 | 提示用户"有新版本，要安装吗？" |
| enableLinuxDesktopAutostart | 主进程→系统 | 设置开机自启 |
| waitForServer | 主进程→本地 | 等待本地服务器启动 |
| stopNextServer | 主进程→本地 | 停止本地服务器 |
| sendToRenderer | 主进程→前端 | 推送消息给前端 |

> 来源：electron/main.js setupIpcHandlers() 调用列表

## 三、6 步启动流程

```
用户双击 OmniRoute 图标
  │
  ▼
步骤 1：Electron 启动
  - 创建 BrowserWindow（1400×900 窗口）
  - 加载 preload.js（预加载脚本）
  大白话：打开一个浏览器窗口，但看起来像原生 App

步骤 2：启动本地服务器
  - startNextServer() 启动 Next.js 服务器
  - waitForServer() 等待服务器就绪
  大白话：在后台启动一个小型网站服务器

步骤 3：加载仪表盘
  - 浏览器窗口加载 http://localhost:{port}
  - 显示 OmniRoute 仪表盘首页
  大白话：在窗口里显示管理页面

步骤 4：创建系统托盘
  - createTray() 创建菜单栏图标
  - 右键菜单：显示/隐藏窗口、退出
  大白话：在菜单栏放一个小图标，方便快速访问

步骤 5：检查更新
  - checkForUpdates() 检查 GitHub Releases
  - 有新版本→ 下载→ 提示安装
  大白话：自动检查有没有新版本

步骤 6：就绪
  - 用户开始使用
  大白话：一切准备就绪，可以开始了
```

> 来源：electron/main.js createWindow() + setupIpcHandlers()

## 四、关键设计决策

| 设计决策 | 大白话 |
|----------|--------|
| contextIsolation: true | 前端代码和主进程代码隔离开，防止注入攻击 |
| nodeIntegration: false | 前端不能直接调用 Node.js，更安全 |
| webSecurity: true | 启用浏览器安全策略 |
| 系统托盘 | 关闭窗口后仍在后台运行，不占用 Dock 空间 |
| 自动更新 | 用户不需要手动下载安装包 |

> 来源：electron/main.js BrowserWindow 配置
