# 03-04 · 仪表盘 (Dashboard) — 深度剖析

> **技术栈**：Next.js 16 + React 19 + Tailwind CSS 4 + Zustand | **路由**：596 个 API 端点 | **页面**：185 个管理页面目录

---

## 定位

仪表盘是 OmniRoute 的"控制中心"。用户通过网页界面管理所有功能：添加提供商、查看用量、配置压缩、启动代理。不需要任何命令行操作。

> 来源：src/app/(dashboard)/ 目录

---

## 生活化比喻

> 仪表盘像**智能家居的中控面板**：一个屏幕上集中控制所有设备——灯（提供商）、空调（压缩）、门锁（安全）、监控（用量）。不用每个设备单独操作，一个面板搞定一切。

## 一、核心管理页面（12 个模块）

| 页面 | 大白话 | 用户能做什么 | 路径 |
|------|--------|------------|------|
| 首页 | 总览仪表盘 | 看系统状态、最近用量、提供商健康 | dashboard/ |
| 提供商管理 | 管理 AI 服务商 | 添加/删除/配置 160+ 提供商 | dashboard/providers/ |
| 提供商详情 | 查看单个提供商 | 配额、用量、健康状态、日志 | dashboard/providers/[id]/ |
| Combo 管理 | 管理提供商组合 | 设置优先级、故障转移策略 | dashboard/combos/ |
| Combo 实验场 | 测试 Combo 配置 | 发送测试请求，看哪个提供商被选中 | dashboard/combos/playground/ |
| 压缩配置 | 管理压缩策略 | 选择 RTK/Caveman，调整强度 | dashboard/compression/ |
| 用量分析 | 查看花了多少钱 | 图表展示 token 消耗和费用 | dashboard/usage/ |
| MITM 代理 | 管理透明代理 | 开启/关闭，查看拦截日志 | dashboard/settings/mitm/ |
| 安全设置 | 管理 API Key 和护栏 | 生成/删除 API Key，配置速率限制 | dashboard/settings/ |
| Webhook 管理 | 管理外部通知 | 配置回调地址 | dashboard/settings/webhooks/ |
| 定时任务 | 管理自动任务 | 配置定时 Ping、配额检查 | dashboard/settings/cron/ |
| 审计日志 | 查看操作记录 | 追溯所有 API 调用 | dashboard/audit/ |

> 来源：src/app/(dashboard)/dashboard/ 目录结构

## 二、关键交互设计

| 交互 | 大白话 | 实现 |
|------|--------|------|
| 实时数据刷新 | 用量数据自动更新，不用手动刷新 | WebSocket 推送 |
| 拖拽排序 | 提供商、Combo 可以拖拽调整优先级 | @dnd-kit 组件 |
| 实时搜索 | 输入关键词快速找到提供商 | 前端搜索过滤 |
| 向导式配置 | 首次使用引导式配置 | 配置向导组件 |
| 暗色模式 | 支持深色/浅色主题切换 | Tailwind 主题 |
| 响应式布局 | 手机、平板、电脑都能用 | Tailwind 响应式 |

> 来源：Next.js 16 + React 19 架构分析
