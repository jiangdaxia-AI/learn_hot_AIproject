## 5.1 实体关系总览

核心数据模型之间的引用关系（→ 表示"引用/依赖"）：

```
Provider (提供商)
  ├──→ Connection (连接凭证：API Key / OAuth Token)
  ├──→ ProviderPlan (配额计划：每月免费额度、限制)
  └──→ ServiceModels (服务模型：支持哪些 AI 模型)

Combo (提供商组合)
  ├──→ Provider[] (包含哪些提供商)
  ├──→ ComboSettings (优先级、故障转移策略)
  └──→ CompressionCombo (关联的压缩配置)

Session (对话会话)
  ├──→ Provider (使用的提供商)
  ├──→ Message[] (包含哪些消息)
  └──→ Usage (消耗的 token 和费用)

User (用户)
  ├──→ ApiKey[] (用户的 API 密钥)
  ├──→ Session[] (用户的所有对话)
  ├──→ Webhook[] (用户配置的回调)
  └──→ Settings (用户偏好设置)

MITM (透明代理)
  ├──→ Target[] (拦截目标：Codex/Cursor/Windsurf 等)
  └──→ ProxyLog[] (拦截日志)
```

## 5.2 核心实体详解

### 5.2.1 Provider（提供商）

| 字段 | 大白话 |
|------|--------|
| id | 唯一编号 |
| name | 名称（如"OpenAI"、"Claude"） |
| provider_type | 类型（API Key / OAuth / Web 客户端） |
| api_key | API 密钥（加密存储） |
| base_url | API 地址 |
| models | 支持的模型列表 |
| is_active | 是否启用 |

### 5.2.2 Connection（连接凭证）

| 字段 | 大白话 |
|------|--------|
| id | 唯一编号 |
| provider_id | 关联的提供商 |
| token_type | 凭证类型（API Key / OAuth Token / Device Code） |
| access_token | 访问令牌 |
| refresh_token | 刷新令牌（OAuth 专用） |
| expires_at | 过期时间 |
| created_at | 创建时间 |

### 5.2.3 Combo（提供商组合）

| 字段 | 大白话 |
|------|--------|
| id | 唯一编号 |
| name | 组合名称 |
| providers | 包含的提供商列表 |
| routing_strategy | 路由策略（优先级/轮询/最低成本） |
| fallback_enabled | 是否启用故障转移 |
| cooldown_config | 冷却配置 |
| budget_cap | 预算上限 |

### 5.2.4 Session（对话会话）

| 字段 | 大白话 |
|------|--------|
| id | 唯一编号 |
| user_id | 用户 |
| provider_id | 使用的提供商 |
| combo_id | 使用的组合 |
| status | 状态（进行中/已完成/错误） |
| input_tokens | 输入的 token 数 |
| output_tokens | 输出的 token 数 |
| total_cost | 总费用 |
| created_at | 开始时间 |
| updated_at | 最后活跃时间 |

### 5.2.5 CronJob（定时任务）

| 字段 | 大白话 |
|------|--------|
| id | 唯一编号 |
| name | 任务名称 |
| schedule | 执行时间（cron 表达式） |
| task_type | 任务类型（配额 Ping / 健康检查 / 清理） |
| provider_id | 关联的提供商 |
| enabled | 是否启用 |
| last_run | 上次执行时间 |
| next_run | 下次执行时间 |

### 5.2.6 MITM Target（拦截目标）

| 字段 | 大白话 |
|------|--------|
| id | 唯一编号 |
| name | 目标名称（如"Codex"、"Cursor"） |
| hosts | 要拦截的域名列表 |
| port | 拦截端口 |
| endpoint_patterns | 要拦截的 API 路径 |
| enabled | 是否启用 |

## 5.3 存储结构

| 存储介质 | 用途 | 存放位置 |
|----------|------|---------|
| SQLite 数据库 | 核心数据（提供商、用户、会话、用量） | 本地文件 |
| 加密存储 | API Key、OAuth Token | 数据库加密字段 |
| 内存缓存 | 压缩缓存、liveZone | 内存（进程重启后丢失） |
| 文件系统 | 日志、临时文件 | 本地磁盘 |
