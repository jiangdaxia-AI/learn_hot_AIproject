## 6.1 术语表

| 术语 | 英文 | 大白话 |
|------|------|--------|
| 提供商 | Provider | AI 服务商，比如 OpenAI、Claude |
| 组合 | Combo | 多个提供商的组合，自动选最优 |
| 压缩 | Compression | 减少发给 AI 的字数，省钱 |
| 故障转移 | Fallback | 一家挂了，自动换另一家 |
| 熔断器 | Circuit Breaker | 连续失败后暂停使用，防止雪崩 |
| 代理 | Proxy | 中间人，转发请求 |
| MITM | Man-in-the-Middle | 拦截请求，替换内容 |
| SSE | Server-Sent Events | 服务器推送，流式传输 |
| OAuth | Open Authorization | 第三方授权登录 |
| 护栏 | Guardrail | 安全策略，限制行为 |
| 令牌 | Token | AI 计费单位，约 0.75 个英文单词 |
| 执行器 | Executor | 模拟 Web 浏览器访问 AI 服务 |
| RTK | RTK Compression | 结构化压缩引擎 |
| Caveman | Caveman Compression | 规则压缩引擎 |
